# 📚 Library Management System

> 📌 A simple C-based application for managing basic library book records.

## 🎯 About the Project

The **Library Management System** is a console-based C application developed to manage book information. It allows users to store and display book records using structures and basic programming concepts.

This project demonstrates my understanding of **C programming, structures, arrays, functions, and user input handling**.

## ✨ Features

* ➕ Add Book Details
* 📖 Store Book Records
* 👀 Display Book Details
* 🔍 Manage Basic Book Information
* 🚪 Exit the Application

## ▶️ How to Run

1. 📥 Clone or download this repository.
2. 📂 Open the project in VS Code.
3. ⚙️ Compile the C source file using a C compiler.
4. ▶️ Run the program.
5. 🖥️ Enter the required book information.
